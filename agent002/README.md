# agent002

**Job since 2026-11-12:** bring players to the browser cooking game Beat The Chefs (`apps/cookgame`) by posting on Bluesky as a labelled bot. The first job (2026-11-07 to 11-12, selling approved affiliate products through dev.to articles and GitHub repos) is parked: what it published stays up and stays audited; `parked.json` switches the publishing tools off.

- **Runtime:** its own Hermes v0.22.5 container `a9n9-agent002` (image built from the official Dockerfile), HERMES_HOME `~/a9n9/agent002/hermes`, bridge network (cannot reach the operator's Chrome on 127.0.0.1:9222 or agent001's services), 3 GB memory cap. Nothing from agent001 is mounted. It reaches the game only over the LAN (`game.json` → `lan`), read-only, through `bin/game`.
- **Model:** Nous Portal Plus (agent002@a9n9.net) over OAuth; weekly included usage ran out 2026-11-11 and resets 2026-11-14 15:32 UTC. Primary `deepseek/deepseek-v4.1-flash-1017`, free fallbacks as before.
- **Tools off in Hermes:** browser, computer_use, cronjob, connections, delegation, tts.
- **Kit (`bin/`, mounted read-only at /agent):**
  - `game today|board|stats|link`: what the agent may know about the game (LAN `/api/today`, `/api/board`, and the host's KPI facts).
  - `bsky-post`, `bsky-read` (`_bsky.mjs`, `_game.mjs`): plain XRPC. Rules in code: 3 posts + 10 replies a day; link card attached by the tool only (`<public>/?s=bsky[-tag]`); no links, @mentions, blocked hashtags or banned wording (television, real chefs, newspapers, prizes, speaking as a person or the maker); replies only to notifications, once each; 48 h repeat guard; a prediction first; the profile must say it is a bot. No like/follow/repost command exists.
  - `pin`: stub (Pinterest Trial API pins are private; Standard access needs a demo video and review).
  - `predict`, `goals`, `kpi`, `journal` as before, with `game.*` metrics. Parked: `devto-post`, `github create|push`, `nostr-post`. Still working: `devto-edit`, `devto-stats`, `github stats|issues`, `judge`.
- **Config the operator sets:** `game.json` (`public` = the address players use; empty = posting tools refuse), `parked.json`, `goals.json`. Secret: `~/a9n9/secrets/agent002-bsky.env` (`BSKY_HANDLE`, `BSKY_APP_PASSWORD`; the account is created by Arun, with a profile that says it is an AI agent / bot).
- **Measurement (host):** `scripts/game-stats.mjs` reads the game's activity log (`apps/cookgame/data/events`), counting only sessions that came through Cloudflare; `kpi-collect.mjs` (hourly) writes `game.visits|started|plated|shared|claimed` for `all`, `agent` (tags starting `bsky` or `pin`) and each `src:<tag>`; `predict-run.mjs` takes baselines and settles from the same reader. The log has no IP, cookie or visitor id by design, so counts measure interest, not people, and anyone can inflate them.
- **Audits (host crontab, every 10 min, pause on breach):** `bsky-audit.mjs` (public feed and profile vs the tool's log and rules; quiet until the secret exists), `devto-audit.mjs`, `github-audit.mjs`, `usage-watch.mjs`. Known limits: the agent can read its app password; likes are not visible to the audit. Do not post from the bot account by hand: the audit treats any post the tool did not log as a breach.
- **Schedule:** Hermes cron `work`, every 4 hours.
- **Stop rule (Arun, 2026-11-12):** 14 days after the game is public, under 50 visits a week from the agent's links or under 5% of finished rounds shared → posting stops and the plan is rethought.
- **Deploy:** `agent002/scripts/deploy.sh`; then copy `SOUL.md` into `hermes/SOUL.md` and `docker restart a9n9-agent002`.
